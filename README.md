# Gesture Synth EDM

A camera-based electronic music synthesizer with hand gesture control - EDM Edition.

## Features

- Hand gesture control using webcam and MediaPipe
- Control chords, tones, and effects with hand gestures
- Built-in drum sequencer with multiple EDM styles (House, Techno, Dubstep, Trance, Drum&Bass, Trap)
- Arpeggiator and looper controls
- Audio effects: Filter, Distortion, Reverb, Delay, Chorus, Compressor, Bitcrush, Flanger, Autofilter
- Visual feedback with webcam overlay, spectrum visualization, volume meter, and chord display
- Responsive design for desktop and mobile browsers

## Local Development

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/nashwu0117/gesture-synth-enhanced.git
   cd gesture-synth-enhanced
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   
   npm run dev
   ```
   npm run dev
   ```

4. Open your browser to `http://localhost:5173` (or the URL shown in the terminal).

## Building for Production

To create a production build:

```bash
npm run build
```

The built files will be in the `dist/` directory.

To preview the production build locally:
```bash
npm run preview
```

## Deployment to GitHub Pages

The `gh-pages` branch contains the built version of the site. To update the GitHub Pages site:

1. Build the project:
   ```bash
   npm run build
   ```

2. Push the contents of the `dist` directory to the `gh-pages` branch. This can be done manually or via a script.

Alternatively, you can set up a GitHub Actions workflow to automate deployment (not currently configured in this repository).

## Project Structure

- `index.html` - Main HTML file
- `main.js` - Main application logic (ES module)
- `package.json` - Project dependencies and scripts
- `dist/` - Built production files (generated by `npm run build`)
- `node_modules/` - Dependencies (not committed)

## Dependencies

- [Vite](https://vitejs.dev/) - Build tool and development server
- [Tone.js](https://tonejs.github.io/) - Web Audio framework for synthesizing and sequencing
