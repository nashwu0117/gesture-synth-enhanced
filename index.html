Gesture Synth EDM Guide

🎹 左手 — 和弦選擇

  • 手指數量：1~5 根手指 = I~V 級和弦
  • Index + Pinky = VI 級和弦
  • Index + Pinky + Thumb = VII 級和弦
  • 手腕內傾 = Major（大調）
  • 手腕外傾 = Minor（小調）

🎛️ 右手 — 音色控制

  • 手指數量：1=原位, 2=第一轉位, 3=七和弦, 4=屬七/減七
  • 高度：越高 = 越大聲
  • 傾斜：內傾=濾波器關閉（溫暖）, 外傾=濾波器打開（明亮/電音）
  • 拇指：內收 = 高八度, 外展 = 低八度

🥁 鼓機 & 序列器

  • 點擊下方網格切換鼓點（Kick/Snare/Hi-Hat/Clap）
  • 6 種預設節奏型：House / Techno / Dubstep / Trance / Drum&Bass / Trap
  • BPM 可調整 60~180

🎚️ 效果器

  • Master Filter：全局低通濾波器 + 共振
  • Distortion：失真/諧波增強
  • Reverb：空間殘響
  • Delay：回聲效果
  • Chorus：合唱/立體聲寬度
  • Compressor：動態壓縮

🎵 琶音器 & 循環

  • 琶音器：左手選和弦後，自動演奏琶音
  • 循環錄音：錄製手勢循環，自動播放
  • LFO Wobble：自動濾波器擺動，製作 Dubstep 風格

🎨 預設風格

  • House：溫暖鋸齒波 + 4/4 鼓組
  • Techno：硬邊方波 + 工業鼓組
  • Dubstep：FM 合成 + Wobble Bass
  • Trance：超鋸齒波 + 延遲 Pad
  • Ambient：純正弦波 + 長殘響
